# RSGT Logistics Analytics Project

**Client:** RSGT Bangladesh Ltd (Chittagong Port)  
**Role:** Data Analyst (Case Study Assignment)

## 📋 Project Overview

Developed a comprehensive data-driven solution to optimize inter-terminal container transfers and forecast workforce requirements for Covered Van (CV) deliveries.

### Case Study 1: Inter-Terminal Transfer Optimization
- Analyzed shuttle operations between Patenga Container Terminal (PCT) and South Container Yard (SCY)
- Identified performance of 3 trucking vendors (Showkat Trading, S.I. Chowdhury, Siam Enterprise)
- Built automated data pipeline and interactive Power BI dashboard

**Key Achievements:**
- Automated data ingestion using **Power Query (From Folder)**
- Identified **SCY Yard processing** as the primary bottleneck (highest delay stage)
- Designed dynamic dashboard with KPI tiles, vendor comparison, and time-of-day analysis
- Delivered actionable recommendations resulting in potential cycle time reduction

### Case Study 2: Predictive Workforce Planning
- Forecasted daily CV deliveries for first 10 days of February 2026
- Incorporated 4-Day Rule, weekly seasonality, and yard density factors

## 🛠️ Tech Stack
- **Data Engineering:** Power Query (M), Excel
- **Visualization:** Power BI
- **Analysis:** Statistical analysis, time-series forecasting
- **Documentation:** Professional reporting

## 📊 Key Insights
- SCY Yard stage accounts for the highest delays
- Evening shifts show significantly longer processing times
- Vendor performance variation is minimal in travel but differs in yard efficiency

## Deliverables
- Automated Power Query data model
- Interactive Power BI Dashboard (.pbix)
- Technical Documentation + Operational Proposal
- CV Delivery Forecast Model
